# Support

Start with [首次成功](docs/FIRST_SUCCESS.md), [FAQ](docs/FAQ.md), and [产品安装与更新](docs/PRODUCT_INSTALL.md).

When opening an Issue, include only:

- KnowledgeRadar version and whether this is a Release install or source checkout;
- the command/action and the redacted error category;
- whether `health_check` works after a Codex refresh.

Never include API keys, tokens, cookies, browser profile directories, full local paths, archives, databases, logs, screenshots containing secrets, or account identifiers. Security and privacy vulnerabilities must follow [SECURITY.md](SECURITY.md), not public Issues.
