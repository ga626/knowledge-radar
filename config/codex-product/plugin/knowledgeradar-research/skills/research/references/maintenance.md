# 维护与恢复：仅在处理相应问题时读

正常交付仍由主 Skill 的绑定、提交、回读完成；以下不是每次研究的检查表。

- 历史归档：新任务按项目／年／月／日／时间任务归档，任务名只留时间与标题；恢复沿原研究日期，不另建“补档”项目。已有文件先计划核对身份与哈希，再原地登记；旧固定证据受控导入保留原 ID，不继承旧评审。使用 `manage_research_artifacts` 的 plan/apply 动作，不绕过用户修改/移动/删除保护。
- 审阅：复杂争议可用现有调查、关键命题、替代品与撤证记录，不新造账本。选择这些动作后遵守其局部前提；普通总结不自动附空审阅表，需要时显式 `include_review`。未审不是程序判假，也不是禁止交付。
- 评测维护：用 `read_knowledge`/`update_research` 的 `action=evaluation` 处理现有队列并留依据。界面纠错待 Agent 接手，不自动启动研究或付费评分；源码测试、正式安装试验与语义质量结果分开。
- 工具故障：先按返回状态区分未执行、未知结果和已完成；查询旧任务/回执不重放。完整能力与浏览器历史只在确需诊断时读，不把旧等待记录当本次登录状态。
