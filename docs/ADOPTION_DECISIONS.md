# P4可选技术采用记录

日期：2026-10-20。本轮保留模块化单体、现有Playwright/解析链和faster-whisper；不为新技术名称增加常驻服务。

| 候选 | 决定 | 进入主链的门槛 |
|---|---|---|
| Crawl4AI | 暂不采用；现有动态提取加逐跳URL边界 | 同一静态/动态/反爬样本，正文与引用正确率改善且不增加后台浏览器/存储成本；确认API与许可 |
| Docling | 暂不采用；PDF保留pypdf，复杂版式明确降级 | 同一带人工标注的表格/扫描样本，版式与字符正确性、内存及冷载成本达到预先固定门槛 |
| SenseVoice | 可选对照，未替换默认 | 中英金标WER/CER、冷载/热转写/峰值内存、模型许可证逐项对照；历史单样本耗时不作为本轮收益 |
| 新MCP Tasks宿主协议 | 暂保留task_id+查询/取消兼容链 | 宿主明确支持后用原生协议重新验收，不把内部TaskService称为MCP Tasks已接通 |

原全产品审计的2026-10-20官方来源与社区记录为调研输入，原始证据仅保留本地。上述门槛不是已测得收益，未安装三个候选库，不宣称质量胜出。
