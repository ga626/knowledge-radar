# 本地控制台

正式版固定为 `http://localhost:18882/`，维护者开发版固定为 `http://localhost:18883/`；对应的 `127.0.0.1` 地址也可访问。Windows 安装用户可直接输入网址或收藏后打开，无需先运行脚本、保留浏览器 Cookie 或携带启动票据。

网页和 API 只监听当前电脑的回环地址。服务会核对浏览器连接所属进程与服务是否属于同一 Windows 用户；无法核对时拒绝访问，Cookie 不能绕过。接口仍检查 Host、Origin、Fetch Metadata 与 CSRF。开发版不随普通用户包注册；每位安装用户使用本机数据。固定端口不支持同一电脑的多个 Windows 用户同时各运行一套实例，遇到其他用户或其他程序占用时拒绝接管。

网页用于配置、查看记录与成果；调研仍在 Codex 对话中提出。账号恢复页在本机显示登记名称、槽位和登记编号，用来确认该扫码的账号。配置接口不回显密钥，研究记录和成果仅在授权的本机页面内查看。

## 平台账号恢复

调用遇到明确的登录或验证要求时，同一事件会更新能力中心的账号卡和全局待处理提示，打开对应账号窗口，并请求 Windows 桌面提醒。网站打开时每两秒读取该事件；未打开网站也能收到桌面提醒，但 Windows 通知设置可能隐藏提醒。辅助进程的显示回执不代表你已看到。

小红书显示正式 A/B/C 的登记全名和数字，实验通道不参与。其他平台使用同一恢复入口。关闭窗口只回收浏览器，未验证的恢复待办保留；点击“已登录，验证恢复”后，必须通过对应 Profile 的探针才解除待办。共享软件错误、限频和模型欠费不会被当作扫码要求。

安装完成后会生成两个等价入口：

- `%LOCALAPPDATA%\KnowledgeRadar\console.cmd`：打开或复用控制台；未运行时启动它。
- `%LOCALAPPDATA%\KnowledgeRadar\configure.cmd`：保留的兼容入口，行为与 `console.cmd` 相同。

`apply` 默认注册当前用户的一个 Windows Task Scheduler 任务，而不再写入“启动”目录。这个任务负责登录启动、有限次数的失败重试及每分钟补启动；`IgnoreNew` 防止重复实例，无运行时限，不因切换电池停止。它只启动 `active.json` 指向的 stable 安装。网页进程异常退出或持续无响应时由现有宿主恢复；宿主退出后由同一个计划任务补启动，无额外巡检程序。

“随时打开”适用于电脑已开机、当前用户已登录且系统已唤醒。关机、睡眠期间网页服务不可访问。唤醒后恢复存在调度延迟；系统错过的触发也不保证立即执行。安装与更新应检验本机计划任务及实际页面，不能只看任务已注册。

若不希望登录时常驻，可在安装时加入 `--no-console-autostart`，或随后运行：

```bat
%LOCALAPPDATA%\KnowledgeRadar\console.cmd --disable-autostart
```

恢复常驻：

```bat
%LOCALAPPDATA%\KnowledgeRadar\console.cmd --enable-autostart
```

控制台由 stable supervisor 单独拥有：它用 Windows named mutex 排除重复守护，记录脱敏状态和日志，并通过 `role + fingerprint + generation` 校验实际 worker 身份。入口会复用同一 supervisor；若固定端口被非 KnowledgeRadar 程序或错误 generation 占用，会报告冲突，绝不抢占或悄悄切换随机端口。更新后使用 `console.cmd --restart` 请求 supervisor 受控重启到当前 `active.json` 指定的产品版本。

开发预览是独立入口，只能由显式开发程序根启动，也不能代替 stable `18882`。维护者可显式启用独立的开发版计划任务，让开发版登录后常驻；普通安装不会创建它。启动参数固定程序根及独立状态根，开发版只读接入正式研究记录，缓存和运行状态隔离。

诊断时可运行入口的 `--status`。它同时核对记录中的宿主 PID 与实际 HTTP 身份，不把陈旧的 `READY` 当作可用。新宿主获取角色互斥锁后，若发现同身份的孤儿网页进程，会通过签名停止协议安全回收，再创建自己管理的网页进程。身份不匹配、端口无响应或无法验证时，不会强杀现有程序。

页面断连会提示正在重试，并保留上次内容；恢复后自动重读当前页面，保留所选栏目。旧令牌会重新获取，权限拒绝不会造成无限刷新。非 Windows 环境保留旧票据兼容路径，不宣称具有 Windows 同用户鉴别保障。
